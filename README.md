```sh
npx skills add lyckantropen/skills --skill <name>
npx skills update   # refresh installed skills later
```

## Skills

**Design, gated.** AI agents close tasks fast and leave the design worse — each diff optimizes for "done," not for the structure holding it. This family of gates fights back, distilling decades of research — software design theory (Parnas, Naur), refactoring and legacy-code practice (Fowler, Feathers), empirical study of how code actually evolves (GitClear, DORA, METR), and systems thinking (POSIWID, requisite variety) — into principles an agent can walk and verdicts a human can check. You invoke them — the cost function that grew the bloat never schedules its own subtraction. Pressure gates each change on entry; strain catches the design deforming as changes bend around it; collapse pays down the mass an agent has already grown.
